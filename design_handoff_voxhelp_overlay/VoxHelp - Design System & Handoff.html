Design System & Handoff

VoxHelp — the invisible AI layer on top of any interview.

VoxHelp listens to live technical interviews on Meet, Teams or Zoom and translates what candidates actually say — in real time — for non-technical recruiters. The interface is a transparent, always-on-top glass overlay that floats beside the call without ever getting in the way.

Electron · always-on-top Glassmorphism React + Tailwind Onest / JetBrains Mono FR / EN
01 — Principles

Design principles

Every decision serves one goal: VoxHelp should feel like a thought surfacing next to the conversation, not an app demanding attention.

Invisible by default

The recruiter must always see the candidate behind the glass. Translucency and blur are non-negotiable, never opaque panels.

AI-native, not a dashboard

Insights read as discrete "thoughts" that fade in as they form. No tables, no KPIs, no chrome that says enterprise SaaS.

Non-intrusive

One column, predictable position, gentle motion. The recruiter glances, absorbs, and returns to the human in front of them.

Decode, don't transcribe

A raw transcript helps no one. Each card answers "what does this mean?" and "what should I ask next?" in plain language.

03 — Components

Component library

Insight card — the floating AI thought

The atom of the product. A semi-transparent card with a colored accent rail, category tag, confidence dots, a plain-language "what this means" body, and an optional highlighted follow-up question.

┌─────────────────────────────────────────────┐ │ ◆ TRADUCTION 07:31 ● ● ○ │ ← category tag · timestamp · confidence │ Architecture serverless maîtrisée │ ← title (insight headline, 14.5/600) │ ────────────────────────────────── │ │ CE QUE ÇA VEUT DIRE │ ← body label (10/700 caps) │ Pipeline complet : déclencheurs, files… │ ← plain-language explanation (13/1.5) │ ┌─ QUESTION DE RELANCE ───────────────────┐ │ ← optional, accent-tinted sub-card │ │ Comment gérez-vous la montée en charge ? │ │ │ └──────────────────────────────────────────┘ │ └─────────────────────────────────────────────┘ hover → lift 1px · stroke brightens · copy/pin actions fade in

Confidence indicator

Three dots + label. ● ● ● Confirmé ● ● ○ Partiel ● ○ ○ À vérifier

Category tags

Icon chip + uppercase label, color-coded: Traduction, Jargon décodé, Point fort, À creuser, Niveau technique.

Panel structure

  • Header — brand mark, role subtitle, and a live status pill (waveform / spinner / pulse) + hide button.
  • Live caption strip — the candidate's current sentence, italicised, with a mic glyph and mini-waveform when speaking.
  • Insight feed — scrollable column of cards, newest appended at the bottom with a one-time glow, auto-scrolled into view.
  • Command bar — Cluely-style action pills (Assist · Follow-ups · Recap), an "Ask VoxHelp" input, and the recording footer (red pulse · timer · Stop).
  • Floating capsule — a separate always-on-top control (logo · status · stop) that mirrors the macOS menu-bar companion pattern.
04 — Motion

Animations & micro-interactions

Motion is soft, brief and purposeful — entrances under 600ms, easing cubic-bezier(.2,.8,.2,1). Everything degrades gracefully under prefers-reduced-motion.

  • Thought-in — new cards fade up 10px with a 3px → 0 blur and slight scale, so insights feel like they "resolve" into being.
  • New-card glow — a colored inset ring on the latest card fades out over 2.4s, then the card settles into the feed.
  • Analyzing shimmer — during analysis the panel border runs an iridescent violet→cyan→indigo sweep (masked 1.5px ring). The Apple-Intelligence "thinking" cue.
  • Live waveform — bars scale on staggered loops while the candidate speaks; freezes to a flat idle when listening.
  • Status spinner — a conic-gradient ring spins during "Analyse…".
  • Hover lift — cards rise 1px, stroke brightens, copy/pin actions fade in from the top-right.
  • Capsule float — a 3px vertical drift loop signals "this window is alive and detached."

06 — Desktop shell

Electron integration

VoxHelp ships as a frameless, transparent, always-on-top BrowserWindow docked to the right edge of the display. The web layer is exactly the prototype in VoxHelp Overlay.html.

// main.js — the overlay window
const overlay = new BrowserWindow({
  width: 420, height: screen.getPrimaryDisplay().workAreaSize.height,
  x: workArea.width - 420, y: 0,
  frame: false,            // no title bar
  transparent: true,       // see the meeting behind the glass
  hasShadow: false,
  alwaysOnTop: true,
  resizable: false,
  skipTaskbar: true,
  vibrancy: 'under-window',  // macOS native blur backing
  visualEffectState: 'active',
  webPreferences: { preload, contextIsolation: true },
});
overlay.setAlwaysOnTop(true, 'screen-saver'); // float above full-screen calls
overlay.setVisibleOnAllWorkspaces(true);
  • Click-through — call overlay.setIgnoreMouseEvents(true, { forward: true }) when the cursor is over empty space so clicks pass to the meeting; re-enable over interactive regions via mouseenter/leave from the renderer.
  • Hide / show — register a global shortcut (e.g. ⌘\) to toggle visibility; the floating capsule's Hide button does the same via IPC.
  • Audio — capture the system/meeting audio with desktopCapturer (or a virtual audio device), stream to your STT + LLM pipeline, and push insight objects to the renderer over IPC. The UI only ever consumes the Insight shape below.
  • Privacy — exclude the window from screen-share with overlay.setContentProtection(true) so it never leaks into the recorded call.
07 — Implementation

React + Tailwind notes for Claude Code

The prototype is plain React; porting to a Tailwind production app is mechanical. Map the tokens into tailwind.config, then each component below is a 1:1 translation.

The Insight data shape

type Insight = {
  id: string;
  cat: 'translation' | 'jargon' | 'strength' | 'risk' | 'level';
  confidence: 'confirmed' | 'partial' | 'low';
  t: string;                 // '07:31' timestamp in the call
  title: string;             // the insight headline
  body: string;              // plain-language "what this means"
  relance?: string;         // optional suggested follow-up
  level?: number;           // 0–1, only for cat: 'level'
};

InsightCard.tsx (Tailwind)

function InsightCard({ ins, isNew }: { ins: Insight; isNew: boolean }) {
  return (
    <article className={cn(
      "group relative rounded-card bg-white/[.045] p-3.5 ring-1 ring-stroke",
      "transition hover:bg-white/[.075] hover:-translate-y-px",
      isNew && "animate-thoughtIn",
    )}>
      <span className={`absolute left-0 inset-y-3 w-[3px] rounded-full bg-${catColor(ins.cat)}`} />
      <header className="flex items-center gap-2 mb-2">
        <CategoryTag cat={ins.cat} />
        <time className="ml-auto font-mono text-[10.5px] text-white/40">{ins.t}</time>
        <Confidence level={ins.confidence} />
      </header>
      <h3 className="text-[14.5px] font-semibold leading-snug text-balance">{ins.title}</h3>
      <p className="mt-2 text-[13px] leading-relaxed text-white/60">{ins.body}</p>
      {ins.relance && <FollowUp>{ins.relance}</FollowUp>}
    </article>
  );
}
